# 🏠 🛠 Home Operations

Ansible project for managing my Homelab infrastructure.

## 📝 Overview

The goals of this repository are:

- Automate the configuration of my Homelab infrastructure and deployment of
  applications.
- Adhere to best practices.
- Learn and test new technologies and concepts.
- Document my Homelab setup and configuration for future reference and in case
  of disaster recovery.
- Share knowledge and learnings with others.
